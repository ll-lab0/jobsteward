GitHub 同步

数据通过你的 GitHub 私有 Gist 跨设备同步（零费用、数据归你）。在另一台设备输入同一令牌，会自动连到同一份备份。
如何获取 GitHub 令牌？（只勾 gist 权限）
  1. 打开 github.com/settings/tokens
  2. 点 Generate new token (classic)，Note 随意填
  3. 权限只勾 gist 这一项（其余别勾）
  4. 生成后复制 ghp_... 粘贴到下方

连接后会自动在你的账户下创建私有 Gist保管数据，作者无法访问、看不到内容。

必填
已开启自动同步：打开或刷新页面即自动把本机改动上传云端、并拉取其他设备更新；也可随时点「立即同步」手动同步。

欢迎使用求职管家

一个纯前端、零依赖的求职管理工具，帮你把投递全流程管清楚：
  • 日历&看板：总览 / 周期趋势，一眼掌握投递全貌
  • JD 自动填充：粘贴 JD 原文自动提取公司、岗位、职责，少手工录入
  • 数据默认存本机浏览器，不联网也照用
💡 想跨设备同步？点顶部「云同步」连接你的 GitHub 私有 Gist（数据归你、免费、作者看不到）。不连也完全可用。连接后任意设备打开即自动同步，无需手动操作。
